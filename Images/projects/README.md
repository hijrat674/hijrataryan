# Project pictures

These assets are local so the gallery does not depend on external image hosts.

## Pictures from existing project folders

- `cotton.jpg`: cotton photograph from the Cotton project's login background.
- `parking.jpg`: garage photograph from the Parking website's service imagery.
- `petrol-station.png`: existing screenshot of the Petrol Station website homepage.
- `courses.png`: existing screenshot of the Education & Courses website homepage.
- `literature.png`: book cover used by the Ehsas Literature website.

## Illustrated previews

The SVG files are original illustrations of the projects' interfaces or functions.
They are not captured application screenshots. The gallery captions identify them
as illustrated previews. Charts and records in the illustrations are sample data.

Replace an illustration with a real screenshot by updating the image's `src`,
`alt`, and figure caption in `index.html`. Keep screenshots free of private data.
